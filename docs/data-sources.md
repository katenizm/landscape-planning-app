# Источники данных

## Основной набор

Основной набор — техническая апробация ver1 по Байкальскому городскому поселению. Используются четыре сохранённых результата:

| Сценарий | Каталог | Отчётный код |
|---|---|---|
| Жилищный | `housing_trial_v2` | `residential` |
| Производственный | `industrial_trial` | `industrial` |
| Рекреационно-туристический | `recreation_tourism_trial` | `recreation_tourism` |
| Транспортно-инфраструктурный | `transport_infrastructure_trial` | `transport_infrastructure` |

Используется `housing_trial_v2`, потому что на неё ссылается `scenario_comparison.csv`. Версия `housing_trial` имеет другую трактовку покрытия и в приложении не используется.

Исходный каталог:

```text
НИР/vs code/ver1
```

Для каждого сценария читаются `scenario_result.csv` и отчёты `boundary_report.json`, `grid_report.json`, `landscape_report.json`, `normative_report.json`, `scenario_report.json`. Граница читается из `housing_trial_v2/working_boundary.gpkg`.

## Сетка и граница

- 94 строки × 73 столбца, 3468 сохранённых ячеек.
- Шаг 500 м.
- Origin: `416500, 5664500`.
- EPSG:32648, WGS 84 / UTM zone 48N.
- Площадь территории: 822,065118 км².
- 362 граничные ячейки.
- Граница: OpenStreetMap, дата обращения 2026-11-10.
- Исходная граница: 1548 точек; для отображения упрощена до 462 точек при допуске 10 м. Площадь при упрощении сохранена с относительной ошибкой не более 0,1%.

Граница OSM может не совпадать с официальной административной границей.

## Нормативные данные

Слой ЗОУИТ используется как первичный скрининг. Он не является юридическим заключением. Условия, основания и актуальность ограничений требуют проверки по первоисточнику.

Площадь вне найденных зон получает `no_known_restrictions`, а не `allowed`. Это означает «в доступном реестре зона не найдена», а не «освоение разрешено».

Доли нормативных статусов могут перекрываться. В 116 сценарных записях сумма долей больше 1 (до 2,0) из-за пересечения зон. Доли не нормируются и не трактуются как взаимоисключающие.

## Ограничения источников

- OSM может быть неполным и неоднородным по покрытию.
- WorldCover имеет пространственное разрешение 10 м и не заменяет полевые наблюдения.
- DEM в отчёте указан без источника и параметров.
- НСПД показывает доступные зоны, а не полный юридический статус земельного участка.
- Дата снимка данных фиксируется в `meta.generated_at` при пересборке.
