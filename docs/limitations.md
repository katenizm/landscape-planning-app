# Ограничения

- Веса, нормализация и пороги демонстрационные и не утверждены для практических решений.
- Нормативный слой — первичный скрининг, не полная юридическая проверка; отсутствие найденного ограничения не означает разрешения.
- Любая положительная доля запрета исключает всю ячейку. Нормативные зоны могут пересекаться.
- Для ячеек с неопределённым статусом в текущем наборе нет физических критериев; их нельзя ранжировать. Другие пропуски и пользовательские фильтры также ограничивают охват поиска.
- Граница OSM не обязательно совпадает с официальной. Данные OSM могут быть неполными, WorldCover не заменяет полевую проверку; происхождение DEM и условия распространения нормативных данных требуют уточнения.
- Ячейка сетки не является готовой площадкой. Нужны дополнительные нормативные и градостроительные проверки, оценка площади и связности.
- Данные являются статическим снимком и не обновляются из источников автоматически.
