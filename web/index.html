Конфликты режимов

Автоматический подбор

Поиск ячеек с минимальной относительной ландшафтной чувствительностью. Нормативный запрет и незавершённая проверка исключаются из рейтинга.

Параметры поиска

Правила рейтинга
  • ячейки с запретом не участвуют;
  • ячейки с неопределённым нормативным статусом (R2) не участвуют, пока индекс не рассчитан;
  • ячейки без полного набора критериев не участвуют;
  • сортировка по возрастанию индекса, затем по большей доле внутри территории.

Поиск автоматически пересчитывается при смене сценария. Кнопка применяет фильтры. Показаны все совпадающие минимумы с точностью сохранения индекса до 6 знаков.

Метод и проверка

Что именно считает приложение, какие параметры использованы и где проходят границы интерпретации.

Последовательность метода

  1. Выбрать сценарий освоения.
  2. Проверить нормативную допустимость по правилам сценария.
  3. Исключить запрещённые и непроверенные части; не рассчитывать для них чувствительность.
  4. Рассчитать четыре ландшафтных критерия только для нормативно допустимых ячеек.
  5. Нормализовать критерии, применить демонстрационные веса и получить индекс SI.
  6. Назначить класс чувствительности по порогам 0,25 / 0,50 / 0,75.
  7. Совместить нормативный статус и класс чувствительности в рекомендуемый режим.

Нормативная проверка не является весом или слагаемым индекса. Запрет нельзя компенсировать низкой чувствительностью.
